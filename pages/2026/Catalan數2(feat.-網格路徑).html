上集回顧

上集 我們通過洛谷P1044的棧序列個數問題認識到Catalan數，並聲稱Catalan數有很多不同的理解和一個通項公式。 今天我們要介紹其中一種理解------網格路徑，並利用算兩次證明Catalan的通項公式。

Catalan數的通項公式

事實上，Catalan數的通項公式是\[C_n=\frac{1}{n + 1} \binom{2n}{n}\]
證明這個通項公式成立的一個有效手段是證明此通項公式的數列actually等於那個 遞推式 。

網格問題

給定正整數\(n\)，小C正站在平面直角座標系的\((0, 0)\)上， 每次他都可以向右或向上行一步(對應的操作是\(x\)或\(y\)座標增加\(1\))。 途中不能經過\((1,1), (2,2), ..., (n-1, n-1)\)點。
問有多少種走法？

利用算兩次的證明

首先，我們證明答案是 \[C_1=1\] \[C_2=1\] \[C_n=\sum_{i=1}^{n} C_{i-1}C_{n-i}(n \ge 3)\]
當\(n=1\)時，只有 \((0, 0)\)->右->上 這種走法，因此\(C_1=1\)。
當\(n=2\)時，只有 \((0, 0)\)->右->右->上->上 這種走法，因此\(C_2=1\)。 當\(n \ge 3\)時
所以有\(\sum_{i=1}^{n} C_{i-1}C_{n-i}\)個合法序列，有如下代碼： 
#include<bits/stdc++.h>
using namespace std;
int main() {
    int n; cin>>n;
    vector<int>dp(n + 1, 0);
    dp[0] = 1; dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            dp[i] += dp[j - 1] * dp[n - j];
        }
    }
    printf("%d\n", dp[n]);
    return 0;
}

Catalan數

這題和Catalan數有甚麼關係呢？我想讀者應該也猜到了----例題的答案就是Catalan數的通項公式。
Catalan數的定義如下：
數列\(\{C_k\}\)滿足 \[C_0=1\] \[C_1=1\] \[C_n=\sum_{i=1}^{n} C_{i-1}C_{n-i}(n \ge 2)\]

Catalan數的其他應用

甚至，Catalan數還有通項公式和多種理解，比如：網格路徑、括號配對，中間通項公式的證明還用到了母函數(生成函數)和泰勒展開。 這些有趣的題裁我們會留到後面再說。散會！
