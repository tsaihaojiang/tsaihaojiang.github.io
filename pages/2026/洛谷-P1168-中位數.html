題目

題目連結
给定一个长度为\(n\)的非负整数序列\(A\)，对于前奇数项求中位数。
其中\(1 \le n \le 10^5\) 和 \(0 \le A_i \le 10^9\)。

解法

我們先嘗試較為暴力的方法，每次都排一次序。代碼是不難得的，但只有40分。 
#include<bits/stdc++.h>
using namespace std;

int n, k;

int main() {
    int n; cin >> n;
    vector<int> a(n + 1, 0);
    for (int i = 1; i <= n; i++) cin >> a[i];

    for (int i = 1; i <= n; i += 2) {
        vector<int> c(a.begin(), a.begin() + i + 1);
        sort(c.begin(), c.end());

        printf("%d\n", c[(i + 1) / 2]);
    }
    return 0;
}
當然也可以用插入排序----每次插兩次，最差時間複雜度為\(O(n^2)\)，在\(n=10^5\)時不保證能通過(儘管我沒有嘗試過)。

正解

存不存在一種算法是"遞推"的呢？換句話說，就是答案可以由上一次的狀態經過常數級的操作得到嗎，再把這次的狀態留給下一個答案嗎？
我們的想法和插入排序差不多----插入新的值，只不過插入排序時間複雜度最差是\(O(n)\)的，我們可否可以精化到對數級甚至是常數級呢？ 當\(n=1\)時，顯然答案是\(a_i\)。\(n \ge 3\)時，我們需要輸入兩個數並插入。
不如，拿一個變量記錄中位數，中位數左邊和右邊分別拿一個數據結構儲存吧！(應該是自然的) 對於\(n \ge 3\)，輸入的兩個數比較它們和中位數大小後決定它們的歸宿。 輸入完畢後，若果左邊和右邊的個數相等，則那個變量裝的明顯就是中位數。 否則，我們可以把多的那邊搬到少的那邊，如圖所示。
由於每次由下的盤面的左和右個數都相等，而每次只會輸入兩次， 所以就算搬也只會搬最「極」的那個 (若多在左邊，則搬左中最大的；反之搬右中最小的)(如圖)。因此，最大和最小堆能夠完美勝任這個數據結構。
最後，只需模擬搬的過程就可以了。代碼奉上。

AC代碼

#include<bits/stdc++.h>
using namespace std;

int n, x, mid;

int main() {
    int n; cin >> n;

    priority_queue<int, vector<int>> pq1;
    priority_queue<int, vector<int>, greater<int>> pq2;

    for (int i = 1; i <= (n + 1) / 2; i++) {
        if (i == 1) {
             cin >> x;
            mid = x;
        } else {
            for (int i = 1; i <= 2; i++) {
                cin >> x;
                if (x >= mid) pq2.push(x);
                else pq1.push(x);
            }
            if (pq1.size() > pq2.size()) {
                int c = pq1.top(); pq1.pop();
                pq2.push(mid);
                mid = c;
            }
            if (pq1.size() < pq2.size()) {
                int c = pq2.top(); pq2.pop();
                pq1.push(mid);
                mid = c;
            }
        }
        printf("%d\n", mid);
    }
    return 0;
}
