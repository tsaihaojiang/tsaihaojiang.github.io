題目

題目連結
有两个长度为 \(N\) 的单调不降序列 \(A,B\) ，在 \(A,B\) 中各取一个数相加可以得到 \(N^2\) 个和，求这 \(N^2\) 个和中最小的 \(N\) 个。

解法

一個容易想的方法是直接記錄這 \(N^2\) 個和，並將它們放入最小堆，然後拿最小的 \(N\) 個數。但只有64分。 
#include<bits/stdc++.h>
using namespace std;

int n;

int main() {
    cin >> n;

    vector<int> a(n + 1, 0);
    for (int i = 1; i <= n; i++) cin >> a[i];

    priority_queue<int, vector<int>, greater<int>> pq;

    for (int i = 1; i <= n; i++) {
        int k; cin >> k;
        for (int j = 1; j <= n; j++) pq.push(k + a[j]);
    }

    for (int i = 1; i <= n; i++) {
        printf("%d ", pq.top());
        pq.pop();
    }

    return 0;
}

正解

既然是兩個非遞減數列，應該會有一些和是可以直接不理的！
想一想，對於每一個 \(a_i+b_j\) ， 定義 \(C_{ij}=(i-1)(j-1)\) 。 \(a_1+b_1, a_1+b_2, ..., a_1+b_{j-1}, a_2+b_1, a_2+b_2, ..., a_2+b_{j-1}, ..., a_{i-1}+b_{j-1}\) 都嚴格不大於它。因此至少有 \(C_{ij}\) 個數不大於 \(a_i+b_j\)，如果 \(C_{ij}\) 都大於 \(N\) 了，那 \(a_i+b_j\) 就一定不會是最小的 \(N\) 個，我們可以不理。
可以判斷 \(C_{ij}\) 的大小決定要不要omit \(a_i+b_j\) ，這樣可以加快程式的速度(說甚麼廢話！)。

AC代碼

#include<bits/stdc++.h>
using namespace std;

int n;

int main() {
    cin >> n;

    vector<int> a(n + 1, 0);
    for (int i = 1; i <= n; i++) cin >> a[i];

    priority_queue<int, vector<int>, greater<int>> pq;

    for (int i = 1; i <= n; i++) {
        int k; cin >> k;
        for (int j = 1; (i - 1) * (j - 1) <= n && j <= n; j++) pq.push(k + a[j]);
    }

    for (int i = 1; i <= n; i++) {
        printf("%d ", pq.top());
        pq.pop();
    }

    return 0;
}
