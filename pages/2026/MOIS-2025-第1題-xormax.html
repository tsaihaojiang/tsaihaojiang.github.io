題目

給定\(n(2 \le n \le 200000)\)個正整數\(a_1, a_2, ..., a_n\)，其中\(1 \le a_i < 2^{10} \)。
對於任意的區間\([L, R](1 \le L \le R \le n)\)，定義\(P(L, R)= a_L \oplus a_{L+1} \oplus ... \oplus a_R \)。
求P(L, R)的最大值。

解法

首先，提到異或和區間，我們可以快速地想到前綴和，因為異或具有前綴和成立的性質。
按照一般的做法，我們計算並記錄\(P(1, 1), P(1, 2), ..., P(1, n)\)。然後從\(1\)至\(n\)中選兩個\(k, c\) 並找到最大值，有如下代碼： 
#include<bits/stdc++.h>
using namespace std;

int n, k, ans;

int main() {
    cin >> n; ans = 0;

    vector<int> pre(n + 1, 0);

    for (int i = 1; i <= n; i++) {
        cin >> k;
        pre[i] = pre[i - 1] ^ k;
    }

    for (int i = 1; i <= 200000; i++)
        for (int j = i + 1; j <= 200000; j++)
            ans = max(ans, pre[j] ^ pre[i - 1]);

    printf("%d", ans);

    return 0;
}
這個代碼的時間複雜度為\(O(n^2)\)，在\(n=200000\)的情況下顯然超爆時，100%TLE。
要怎樣優化呢？
注意到(這樣說很不要臉)：\(a_i < 1024\)，所以所有的\(P(L,R)\)都會小於\(1024\)，這很關鍵。 由於題目不要求我們輸出最大值時的\(L,R\)，所以我們只需發慮所有\(P(1,k)\)的值。
把所有\(P(1,k)\)於入一個集合中(終於體驗到集合的便捷性)，然後再1024選2個求最大值便可以了， 這時的時間複雜度至多為\(2^{20}\)，這個量小於\(10^8\)，尤其在xor運算十分快的情況下，一定可以通過。

AC代碼

#include <bits/stdc++.h>
using namespace std;

int n, k, ans;

int main() {
    cin >> n; ans = 0;

    vector<int> pre(n + 1, 0);
    set<int> a; a.insert(0);

    for (int i = 1; i <= n; i++) {
        cin >> k;
        pre[i] = pre[i - 1] ^ k;
        a.insert(pre[i]);
    }

    for (auto i : a)
        for (auto j : a)
            if (i != j) ans = max(ans, i ^ j);
    printf("%d", ans);

    return 0;
}
